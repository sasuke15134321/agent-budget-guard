# Agent Budget Guard API - Skill Reference

## Payment support
- USDC (Base mainnet)
- JPYC (Polygon)
- x402 protocol compatible
- HashPort compatible
- zERC-20 ready (planned)

## Market context
JPYC x402 payments on Polygon mainnet are now live via Coinbase CDP Facilitator.
The next layer needed is pre-payment control.
Agent Budget Guard sits before the facilitator:
- Who is allowed to pay
- How much per day
- Which APIs are approved
- JPYC vs USDC routing
- Audit log for enterprise use
